# UX profile

- **Aesthetic reference:** Custom: ornate Islamic-heritage invitation. Gold on deep emerald, Nastaliq display type, Naskh body, generous spacing, restrained motion.
- **Accessibility target:** WCAG 2.1 AA (4.5:1 body text, 3:1 large text and borders, 44px tap targets, visible focus, reduced-motion honored).
- **Brand tone:** Warm and humancentric. Respectful Urdu copy, clear, never pushy.
- **Icon library:** Project inline SVG only (no package). One stroke style, no emoji as UI icons.

## Banned
- Rainbow or multi-hue gradients on CTAs (the single gold gradient is the brand and is allowed)
- Glass blur without a visible gold 1px border and a mostly opaque fill
- Cartoon illustrations
- Decorative icons inside inputs
- Nested scrollbars
- Autoplay sound

## Rules of thumb
- Urdu first, English as a quiet secondary line (`lang="en"`, `dir=ltr`).
- Motion uses transform and opacity only; everything must respect `prefers-reduced-motion`.
- Check at 375px and 1280px: no horizontal overflow before shipping.
- Edit `src/` and run `python3 build.py`; never hand-edit `index.html`.
